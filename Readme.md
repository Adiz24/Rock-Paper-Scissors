# ✊ Rock Paper Scissors Game ✋

## 🎮 About the Project

A simple command-line **Rock Paper Scissors Game** developed using Python. The user plays against the computer, which randomly selects Rock, Paper, or Scissors.

The game consists of **3 rounds**, and the player with the highest score wins!

## 🛠️ Technologies Used

- 🐍 Python
- 🎲 Random Module
- 🔀 Conditional Statements
- ⚙️ Functions
- 🔁 Loops

## 📜 Game Rules

| Choice | Number |
|---|---|
| ✊ Rock | 1 |
| ✋ Paper | 2 |
| ✌️ Scissors | 3 |

**Winning Rules:**
- ✊ Rock beats ✌️ Scissors.
- ✌️ Scissors beats ✋ Paper.
- ✋ Paper beats ✊ Rock.
- 🤝 If both choose the same option, it's a draw.

## ✨ Features

- 🎲 Computer generates random choices.
- 🏆 Best-of-3 rounds.
- 📊 Tracks user and computer scores.
- 🎯 Displays the final match result.
- 💻 Simple and interactive command-line interface.

## 🚀 How to Run

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Navigate to the project folder**

```bash
cd Rock-Paper-Scissors
```

**3. Run the Python file**

```bash
python rock_paper_scissors.py
```
